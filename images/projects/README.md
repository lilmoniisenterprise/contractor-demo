# Local project photos

The demo hotlinks licensed Unsplash photos so the repository stays small.

To use your own (or a client's) photos instead:

1. Export images at about 1600px on the long edge, JPG or WebP, under 300 KB each.
2. Save them here, e.g. `images/projects/cedar-ridge-1.jpg`.
3. In `js/script.js`, change the `img()` helper or replace the IDs in the `PROJECTS` array with
   relative paths such as `"images/projects/cedar-ridge-1.jpg"` (see the README section
   "Replacing photos").

Only publish photos you own or are licensed to use, and only label work as completed by the
company if it actually is.
